# Pawan Kumar Jha — E-Portfolio

## Project Overview
Recruiter-facing e-portfolio for Pawan Kumar Jha, PGDM (Marketing), FIIB New Delhi. The portfolio preserves the approved black-and-gold visual identity while presenting professional experience, skills, evidence-led academic projects, certifications and contact links.

## Portfolio focus
- Digital Marketing & Brand Strategy
- CRM & Customer Retention
- Sales & Distribution
- Client Engagement & Market Research
- Data-informed decision making

## Evidence included
The `public/evidence/` folder contains selected academic project reports. Project descriptions distinguish academic modelling/projections from verified outcomes.

## Key links

- GitHub: https://github.com/27-pawanjha-lang

## Run locally
`npm install` then `npm run dev`

## Build
`npm run build`

## AI-use note
AI was used to review the existing portfolio against the FIIB e-portfolio framework, improve clarity, connect working professional/evidence links, and prepare deployment files. The original visual structure and black-gold design were retained. Factual content was grounded in the supplied resume and project evidence, and unsupported claims were not intentionally added.
