# Golden Horizon Portfolio

Create a premium, modern, highly professional personal e-portfolio website for **Pawan Kumar Jha**, a PGDM student specializing in **Marketing and Wealth Management**, with experience in client handling, investment advisory support, market research, digital marketing, and business analysis.

The website should have a **luxury professional golden theme** inspired by premium finance and consulting websites.

## DESIGN STYLE

Use a sophisticated and elegant visual identity:

* Primary color: Deep Charcoal / Black
* Accent color: Premium Metallic Gold
* Secondary color: Warm Off-White / Ivory
* Use subtle gradients, glassmorphism, soft shadows, and smooth animations.
* Overall feel: Premium, trustworthy, intelligent, ambitious, modern, and corporate.
* Use a clean professional font such as Inter, Manrope, or Sora.
* Make the design fully responsive for desktop, tablet, and mobile.
* Use a premium dark-mode-first interface with gold highlights.
* Add smooth scrolling, subtle hover animations, animated counters, elegant section transitions, and modern micro-interactions.
* Avoid excessive animations or flashy design. Keep it professional and executive-level.
